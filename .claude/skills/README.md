# Skills — core (any pack)

These are framework-level skill files loaded for every client regardless of industry pack. They cover topics that apply across all commercial engagements.

Pack-specific skills live under `verticals/<pack>/skills/`. For the shipping real-estate-uae pack, see `verticals/real-estate-uae/skills/README.md`.

## Catalog

- `cco-kpi-framework.md` — Five-family KPI taxonomy (commercial outcomes, channel health, finance discipline, regulatory hygiene, relationship capital) used by `cco-morning-brief`, `decision-router`, and every cadenced report
- `crm-data-model.md` — Cross-industry CRM object model (Account / Contact / Opportunity / Engagement) and the data-quality contract that `data-quality-steward` enforces
- `marketing-attribution.md` — Attribution-pipeline conventions (UTM hygiene, identity resolution, multi-touch rollup) used by `analytics`, `martech-ops-specialist`, and `marketing-financial-manager`

## Authoring rules

Same as pack skills: framework, not current truth. Edits route through the `knowledge` agent with `chief-commercial-officer` sign-off.
